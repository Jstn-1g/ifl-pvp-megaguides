# Public export scope

This directory is the canonical public source repository for IFL PvP MegaGuides.

- It was not cloned from, created as a worktree of, or initialized from the private repository history.
- The former mixed-rights source and its complete Git history remain preserved in a separate private archive; no private object was imported here.
- Code is re-authored or individually reviewed before inclusion.
- Publisher game artwork, gameplay screenshots, videos, third-party fonts, publisher logos, scraped or synchronized datasets, deployment credentials, private reports, and the legacy editorial corpus are excluded. The only binary files are six reviewed, hash-pinned first-party presentation assets: one reserved project logo, two project-directed franchise-neutral illustrations, one generated social card, and two interface captures.
- Current guides remain evidence-held until their factual review is complete.
- The public visual system uses the approved IFL PvP identity mark, original franchise-neutral genre-world and fantasy-arena artwork, system typography, and CSS motion rather than third-party imagery.

The private migration record retains source-custody, recovery, and rollback evidence outside this public repository.
