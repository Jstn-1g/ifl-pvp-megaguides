# Public export scope

This directory is a fresh, noncanonical release candidate for IFL PvP MegaGuides.

- It was not cloned from, created as a worktree of, or initialized from the private repository history.
- The private source remains the canonical product repository until this candidate passes every release gate.
- Code is re-authored or individually reviewed before inclusion.
- Game artwork, screenshots, videos, fonts, publisher logos, scraped or synchronized datasets, deployment credentials, private reports, and the legacy editorial corpus are excluded.
- Current guides remain evidence-held until their factual review is complete.
- The public visual system uses typography and CSS geometry rather than third-party imagery.

See the private migration manifest for source custody and rollback evidence.
